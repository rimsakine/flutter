# EMSI Connect 🎓

**EMSI Connect** est une application mobile développée avec Flutter pour faciliter l'accès des étudiants à leurs informations universitaires.

## ✨ Fonctionnalités

- 📚 **Mes cours** : accès aux informations relatives aux cours.
- 📅 **Planning** : consultation de l'emploi du temps.
- 👤 **Profil** : accès aux informations personnelles.
- ✅ **Mes tâches** : organisation et suivi des tâches.
- 🔔 **Notifications** : accès aux notifications de l'application.

## 🛠️ Technologies utilisées

- **Flutter** : développement de l'interface mobile.
- **Dart** : langage de programmation.
- **Material Design** : composants graphiques de l'application.

## 🚀 Installation et exécution

1. Clonez le dépôt :

   ```bash
   git clone https://github.com/rimsakine/flutter.git
   ```

2. Accédez au dossier du projet :

   ```bash
   cd flutter
   ```

3. Installez les dépendances :

   ```bash
   flutter pub get
   ```

4. Lancez l'application :

   ```bash
   flutter run
   ```
